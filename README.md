# ROBLOX RUSSIAN — Вселенная

Фанатский 3D-лендинг про Roblox: живой остров из блоков, аватар с двумя скинами
на настоящих текстурах, танец под бит и тихая ночь у костра. Одна страница,
three.js в браузере, без сборки и бэкенда.

## О проекте

Одностраничный сайт-концепт, который встречает вас загрузочным экраном с
красным кубом, а затем вываливается в космическую вселенную: парящий остров
из LEGO-подобных блоков, неоновые кольца, летающие кубы, облака и звёзды.
В центре — блочный аватар в стиле Roblox, который живёт своей жизнью: смотрит
в камеру, моргает, ухмыляется и качает головой строго по ударам трека.

У сайта два режима. **«Бит»** — день, фонк и полная энергия: музыка `track.mp3`,
широкая улыбка, прищур под бас, вспышки и пульсация сцены на акцентах.
**«Ночь»** — тёмное небо, горящий костёр, персонаж сидит на бревне и слушает
`old-song.m4a` с грустным, уставшим лицом. Переход между режимами плавный:
свет, туман и неон гаснут вместе с музыкой.

Отдельная гордость — **скины**. «Кэмп» — чёрный адидас с тремя полосками,
кепка, наушники и растрёпанные волосы. «Кач» — рельефное тело с цепью-крестом,
кепка и штаны с белым граффити. Оба собраны не из цветных материалов, а из
**настоящих текстур пака**: скрипт нарезает плитки, подгоняет их под пропорции
каждой грани блока и раскладывает по материалам. Переключаются одним кликом.

## Что умеет

- **Прокрутка-навигация** по четырём разделам: Главная, Игры, Аватары, О платформе —
  с плавным полётом камеры и параллаксом от мыши.
- **Танец по битам**: карта ударов на 158 точек под трек 75.7 BPM вшита в код,
  есть компенсация задержки вывода звука и ручная подстройка синхронизации.
- **Живая мимика** на canvas: брови, веки, взгляд, улыбка, высунутый язык.
  Днём — ухмылка и прищур под бас, ночью — печаль, усталость и медленные моргания.
- **Два скина** с переключением КЭМП / КАЧ и переключателем БИТ / НОЧЬ в доке.
- **Звук**: громкость, мьют, эффекты приглушаются вместе со звуком.
- **Случайный образ** и кепка вкл/выкл.
- Аватары, игры и цифры платформы — всё в одном экране, без переходов между страницами.

## Управление

| Действие | Что делает |
|---|---|
| `←` `→`, свайп | переключение разделов |
| мышь | параллакс камеры |
| `[` `]` | подстройка синхронизации танца (±5 мс) |
| кнопки в доке | звук, БИТ / НОЧЬ, КЭМП / КАЧ |

## Технологии

- **three.js 0.160** через importmap с jsdelivr: сцена, PBR-материалы, тени, туман.
- **EffectComposer + UnrealBloom** — неоновое свечение, сила которого зависит от баса.
- **Кастомные шейдеры**: купол-небо, мерцающие частицы, энергетические кольца.
- **Web Audio API** — анализатор частот для реакции сцены на музыку.
- **Pillow (Python)** — нарезка пака текстур и подгонка плиток под грани блоков;
  результат запекается в `tex-data.js` как data-URL, поэтому сайт работает и
  с локального диска, и с любого хостинга без CORS.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | вся страница: сцена, аватар, танец, скины, интерфейс |
| `tex-data.js` | 64 текстуры скинов (нарезка пака) в виде data-URL |
| `track.mp3` | дневной трек, под него танцует персонаж |
| `old-song.m4a` | ночной трек у костра |
| `.nojekyll` | отключает Jekyll на GitHub Pages |

## Как выложить на GitHub Pages (5 минут)

1. Зайди на github.com → **New repository**.
   - Имя: например `roblox-russian`
   - Поставь **Public** (для бесплатного Pages нужно именно так)
   - Не добавляй README — у нас он уже есть. Жми **Create repository**.

2. На странице репозитория нажми **Add file → Upload files**.
   Перетащи в окно **всё содержимое этой папки** (не саму папку, а файлы внутри):
   ```
   index.html
   tex-data.js
   track.mp3
   old-song.m4a
   .nojekyll
   README.md
   ```
   Важно: файлы должны лежать **в корне** репозитория, а не в подпапке.

3. Внизу нажми **Commit changes**.

4. В репозитории: **Settings → Pages**.
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)**
   - **Save**

5. Через 1–2 минуты сайт откроется по адресу:
   ```
   https://ТВОЙ_ЛОГИН.github.io/roblox-russian/
   ```
   Ссылку Pages покажет в Settings → Pages сверху.

## Если открыть локально

`index.html` можно открывать двойным щелчком — работает и через `file://`,
и через любой хостинг: все текстуры лежат внутри `tex-data.js` в виде data-URL,
поэтому ничего не «отваливается» по CORS.

Внешние зависимости подтягиваются с CDN (jsdelivr): three.js 0.160 и шрифты.
Нужен интернет — как и при локальном открытии.

## Обновить сайт

Просто загрузи новый `index.html` через **Add file → Upload files** —
GitHub перезапишет старый, Pages обновится сам за минуту.
